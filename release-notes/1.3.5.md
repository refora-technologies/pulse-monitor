## New

- Pulse can now show your readings inside your games, so they stay on screen in full-screen games too. Turn on "Show Pulse inside games" in the control panel. It stays off until you turn it on.
- Out of the box it is a slim line at the top centre of the screen, set flush with the edge. You can move it, resize it, change its opacity and background, or show it as a list instead.
- It has its own readings: frame rate, 1% low, GPU temperature, GPU usage and CPU temperature to start with. Choose others and put them in any order, or use the same ones as your overlay.
- While it shows in a game, your normal overlay steps aside. It comes back when you minimise or close the game.
- It never goes into games with anti-cheat, such as Valorant, Fortnite, Apex Legends or Counter-Strike 2. There your normal overlay keeps showing. You can also turn it off for any single game.
- It appears a few seconds after a game starts, once Pulse has checked the game for anti-cheat.
- If Pulse does not recognise a game as one, you can tell it to show there from the control panel.
- It works in 64-bit games that use DirectX 11 or 12.

## Improved

- Pulse now runs on .NET 10.0.14, which includes Microsoft's latest security fixes.
