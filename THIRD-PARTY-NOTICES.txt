SENSOR DRIVER NOTICE
====================

Setup offers to install PawnIO, a small kernel driver that lets Pulse read
CPU temperature, CPU power and CPU clock. It is ticked by default on the next
page, and you can untick it. Everything else in Pulse works without it, and
you can install it later from Pulse by clicking one of those tiles.

  - FACEIT's anti-cheat will not start while PawnIO is installed. If FACEIT
    is on this PC, Setup unticks the driver for you.
  - PawnIO is used by LibreHardwareMonitor and other hardware monitoring tools.
  - It is signed through Microsoft's Windows Hardware Compatibility program.
  - Uninstalling Pulse asks whether to remove it. If this version of Pulse
    installed it, the answer defaults to Yes. Otherwise it defaults to No,
    because another application may be using it.
